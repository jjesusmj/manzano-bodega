# Capacidad Depósitos Bodega · Aceites Manzano

App web para calcular kilos y litros de los depósitos de oliva y semillas.

- Pantalla: esta web (GitHub Pages).
- Datos: Google Sheet "Capacidad Depósitos Bodega", servido por Google Apps Script.
- `config.js` guarda la dirección del Apps Script (termina en `/exec`).

Fórmula: KG = CM × k + desnivel · Litros = KG ÷ densidad.
